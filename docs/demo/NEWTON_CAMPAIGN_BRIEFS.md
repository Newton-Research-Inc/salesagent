## Campaign 1: Nike Air Jordan Launch

**Client**: Nike Inc.  
**Campaign ID**: `nike_air_jordan_q4_2025`  
**Principal**: `nike` (ESPN tenant)

### Campaign Objective
Launch the new Air Jordan line to sports enthusiasts and basketball fans during Q4 2025 basketball season.

### Target Audience
- **Demographics**: Adults 18-35, Male-skewed (70/30), Urban markets
- **Interests**: Basketball, Sports, Sneakers, Streetwear, NBA
- **Geography**: US (Priority: Major metro areas - NY, LA, Chicago, Atlanta)
- **Devices**: Mobile-first (60%), Desktop (40%)

### Budget & Timeline
- **Total Budget**: $50,000 USD
- **Flight Dates**: December 1, 2025 - December 31, 2025
- **Daily Budget**: ~$1,600/day
- **Pacing**: Front-loaded (higher spend early in campaign)

### Performance Goals
- **Primary KPI**: 10 million impressions
- **Secondary KPI**: 100,000 clicks (1% CTR target)
- **CPM Target**: $5-8 (willing to pay premium for sports inventory)
- **Viewability**: 70%+ viewability rate required

### Creative Requirements
- **Formats Needed**:
  - Display 728x90 (Leaderboard) - Primary format
  - Display 300x250 (Rectangle) - Secondary
  - Display 320x50 (Mobile Banner)
- **Creative Assets**: Provided (Nike brand guidelines compliant)
- **Message**: "Elevate Your Game - New Air Jordan Collection"
- **Call-to-Action**: "Shop Now" → nike.com/airjordan

### Inventory Preferences
- **Preferred Publishers**: ESPN, Sports-focused sites
- **Preferred Placements**: 
  - ESPN Homepage (highest priority)
  - Live game coverage pages (high engagement)
  - Mobile app inventory
- **Content Adjacency**: Sports content, avoid negative news

### Buying Strategy
- **Pricing Model**: CPM (Cost per thousand impressions)
- **Buying Type**: Guaranteed (need certainty for launch)
- **Frequency Cap**: Max 3 impressions per user per day
- **Dayparting**: Evenings/Weekends (peak sports viewing)

### Success Criteria
✅ Campaign launches on time (Dec 1)  
✅ Achieves 10M impressions within budget  
✅ Maintains 70%+ viewability  
✅ Delivers on premium sports inventory (ESPN)

## Newton's Buying Decision Framework

When evaluating which sales agent/products to use, Newton should consider:

### 1. Audience Alignment
- Does the publisher's audience match the campaign's target?
- Nike → ESPN (sports fans) ✅
- Coca-Cola → CNN (broad news audience) ✅
- Apple → NYT (affluent, educated) ✅

### 2. Budget Efficiency
- Compare CPM rates across publishers
- Consider inventory availability vs. budget
- Calculate total impressions achievable

### 3. Inventory Quality
- Viewability rates
- Brand safety/content adjacency
- Placement prominence (homepage vs. ROS)

### 4. Format Availability
- Do products support required creative formats?
- 728x90, 300x250, 320x50 most common
- Premium formats (970x250) for higher-value campaigns

### 5. Delivery Confidence
- Guaranteed vs. non-guaranteed inventory
- Historical delivery performance
- Pacing capabilities

## Using These Briefs with Newton

### Discovery Phase
```python
# Newton calls get_products on each sales agent
espn_products = await espn_client.call_tool("get_products", {
    "brief": "Display inventory for sports brand targeting basketball fans"
})

cnn_products = await cnn_client.call_tool("get_products", {
    "brief": "News inventory for holiday brand awareness campaign"
})

nyt_products = await nyt_client.call_tool("get_products", {
    "brief": "Premium inventory for tech product launch to affluent audience"
})
```

### Evaluation Phase
Newton's LLM reviews returned products against campaign brief:
- Budget: Can afford recommended CPM?
- Audience: Does targeting match campaign needs?
- Format: Creative format supported?
- Scale: Enough daily impressions available?

### Purchase Phase
```python
# Newton creates media buy for selected products
media_buy = await espn_client.call_tool("create_media_buy", {
    "promoted_offering": "Nike Air Jordan Collection",
    "buyer_ref": "nike_air_jordan_q4_2025",
    "packages": [
        {
            "package_ref": "pkg_001",
            "product_ref": "espn_homepage_leaderboard",
            "start_date": "2025-12-01",
            "end_date": "2025-12-31",
            "pricing": {
                "pricing_model": "CPM",
                "rate": 12.00,
                "currency": "USD"
            },
            "inventory_requests": [
                {
                    "quantity": 4000000,  # 4M impressions
                    "unit": "IMPRESSIONS"
                }
            ]
        }
    ]
})
```
